### 2017.06.25 { #june-25-2017 }
<a id="june-25-2017-change-of-features"></a>
#### 機能変更

* 取引先名照会機能を追加
    * 付加オプション機能で、該当事業者番号に対する取引先名を照会できます。
    
<a id="dec-17-2015"></a>
### 2015.12.17 { #dec-17-2015 }
<a id="dec-17-2015-release-of-new-service"></a>
#### 新規サービスリリース
* Corporation Searchサービスリリース
    * 国税庁で管理する事業者番号に対して課税タイプ、新規登録、休廃業しているかどうかおよび取引先名を照会できるサービスです。
